# 🍊 Quitanda do Zé

Página web de uma loja virtual de hortifrúti, com catálogo de produtos, carrinho de compras funcional e design responsivo.

## 📁 Estrutura

```
loja-teste/
├── index.html    # Estrutura da página
├── style.css     # Estilização completa
├── script.js     # Lógica do carrinho e interações
└── README.md     # Este arquivo
```

## 🚀 Como usar

1. Abra o arquivo `index.html` em qualquer navegador moderno
2. Navegue pelos produtos e use os filtros por categoria
3. Adicione itens ao carrinho clicando no botão `+`
4. Visualize o carrinho clicando no ícone 🛒 no topo
5. Ajuste quantidades ou remova itens conforme necessário
6. Finalize o pedido pelo botão "Finalizar Pedido"

## ✨ Funcionalidades

- ✅ Catálogo com 9 produtos (frutas, verduras e legumes)
- ✅ Imagens reais dos produtos
- ✅ Filtros por categoria (Todos / Frutas / Verduras / Legumes)
- ✅ Carrinho lateral funcional com:
  - Adicionar/remover itens
  - Alterar quantidades (+/-)
  - Cálculo automático do total
  - Contador de itens no header
- ✅ Notificações toast ao adicionar produtos
- ✅ Design responsivo (desktop, tablet e mobile)
- ✅ Animações suaves e efeitos hover
- ✅ Seções: Hero, Benefícios, Produtos, Sobre, Contato
